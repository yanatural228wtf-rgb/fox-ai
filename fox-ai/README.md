# Fox AI

Чат-интерфейс (один `index.html`) + маленький Flask-сервер. Работает с бесплатными
моделями (Groq, OpenRouter, Ollama) и с Claude. Можно установить как приложение
на ПК и телефон (PWA).

> Блок между `---` вверху — настройки для Hugging Face Spaces, не удаляй его.

---

## 🚀 Как выложить в интернет, чтобы работало 24/7 без твоего ПК

Важно: **Ollama на хостинге работать не будет** — он крутится на твоём компьютере.
Для 24/7 нужен облачный ИИ. Самый выгодный бесплатный — **Groq**
(около 1000 запросов в день на модель). Запасной — OpenRouter (`:free` модели).
Проверь, доступна ли регистрация в твоей стране, — условия у сервисов меняются.

### Шаг 1. Получи ключ ИИ
1. Зарегистрируйся на https://console.groq.com
2. **API Keys → Create API Key**, скопируй ключ `gsk_...`. Никому его не показывай.

### Шаг 2. Выбери хостинг

#### Вариант A — Hugging Face Spaces (⚠️ с октября 2026 Docker-Space стал платным, нужен PRO)
1. Зарегистрируйся на https://huggingface.co
2. **New → Space**. Имя: `fox-ai`. SDK: **Docker** → *Blank*. Hardware: **CPU basic (free)**.
3. Загрузи все файлы проекта (**Files → Add file → Upload files**): `server.py`, `index.html`,
   `requirements.txt`, `Dockerfile`, `README.md`, `manifest.webmanifest`, `sw.js`, папку `icons`.
   **Файл `.env` НЕ загружай.**
4. **Settings → Variables and secrets**:
   - Secret `OPENAI_API_KEY` = твой ключ `gsk_...`
   - Variable `OPENAI_BASE_URL` = `https://api.groq.com/openai/v1`
   - Variable `OPENAI_MODEL` = `openai/gpt-oss-120b`
   - (по желанию) Secret `ACCESS_PASSWORD` — если хочешь пускать только своих
5. Подожди сборку (2–3 мин). Сайт будет по адресу вида
   `https://ТВОЙ-НИК-fox-ai.hf.space` — именно эту ссылку давай людям
   (она открывается на весь экран и ставится как приложение).

Бесплатный Space засыпает, только если к нему **2 суток** никто не заходил;
первый заход после сна будит его примерно за минуту.
Код публичного Space виден всем — поэтому ключ хранится только в Secrets.

#### Вариант B — Render через GitHub (бесплатно, рекомендую)
1. Залей проект в репозиторий на GitHub (без `.env`, он уже в `.gitignore`).
2. https://render.com → **New → Blueprint** → выбери репозиторий. Render прочитает `render.yaml`.
3. Когда спросит `OPENAI_API_KEY` — вставь ключ. `ACCESS_PASSWORD` можно оставить пустым.
4. Адрес будет вида `https://fox-ai-xxxx.onrender.com`.

Бесплатный Render **засыпает через 15 минут** без посетителей и просыпается ~1 минуту.
Чтобы он не спал: заведи бесплатный монитор на https://uptimerobot.com или
https://cron-job.org, который раз в 10 минут открывает `https://ТВОЙ-АДРЕС/api/health`.
750 бесплатных часов в месяц хватает на один сервис 24/7.

#### Вариант C — свой VPS (самый надёжный, ~3–5 $/мес)
```bash
docker build -t fox-ai .
docker run -d --restart=always -p 80:7860 --env-file .env fox-ai
```

### Шаг 3. Проверь
Открой `https://ТВОЙ-АДРЕС/api/health` — должно быть `"demo": false` и `"provider": "openai"`.
Если `"demo": true` — переменные не подхватились, проверь их имена.

## 📱 Приложение на ПК и телефон

Сайт сделан как PWA — ставится как обычное приложение, со своей иконкой и в отдельном окне.

| Где | Как установить |
|---|---|
| **ПК** (Chrome, Edge, Яндекс) | Кнопка **«Установить»** в шапке сайта или значок ⊕ в адресной строке |
| **Android** (Chrome) | Кнопка **«Установить»** или меню ⋮ → *Установить приложение* |
| **iPhone / iPad** (Safari) | **Поделиться** → **На экран «Домой»** |

Обновления приходят сами: поменял код на хостинге — у всех обновилось.
Если захочешь в Google Play / Microsoft Store — сайт можно упаковать на https://www.pwabuilder.com.

## 🛡 Защита при публичном доступе

Все настройки — переменными окружения (в `.env` или в настройках хостинга):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `RATE_PER_MIN` | 10 | сообщений в минуту с одного IP |
| `RATE_PER_DAY` | 150 | сообщений в сутки с одного IP |
| `ACCESS_PASSWORD` | пусто | если задан — браузер спросит пароль (логин любой) |
| `MAX_MESSAGE_CHARS` | 8000 | максимальная длина сообщения |

Лимиты нужны, чтобы чужие люди не сожгли твой бесплатный лимит Groq за час.
Помни: лимит ключа общий на всех пользователей сайта.

## 💻 Локальный запуск

```bash
cd fox-ai
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
python server.py
```

Открой http://localhost:5000. Без настроек в `.env` сервер отвечает заглушкой (демо-режим).

### Бесплатные варианты ИИ

| Вариант | Цена | Ключ | Работает 24/7 на хостинге |
|---|---|---|---|
| **Groq** | бесплатный тариф (~1000 запросов/день) | нужен | ✅ |
| **OpenRouter** `:free` | бесплатные модели (~50 запросов/день без пополнения) | нужен | ✅ |
| **Ollama** | бесплатно, без лимитов | не нужен | ❌ только пока включён твой ПК |
| **Claude** | платно | нужен | ✅ |

Лимиты и условия меняются — проверяй на сайтах провайдеров.

## Веб-поиск

- С **Claude** используется встроенный поиск API.
- С бесплатными провайдерами поиск идёт через DuckDuckGo (пакет `ddgs`, ключ не нужен).
  Если поиск временно недоступен, бот ответит без него, а не ошибкой.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | интерфейс, история чатов в localStorage браузера |
| `server.py` | `/api/chat`, `/api/web-chat`, `/api/health`, отдаёт сайт и PWA-файлы |
| `manifest.webmanifest`, `sw.js`, `icons/` | установка как приложение |
| `Dockerfile` | запуск на Hugging Face / VPS |
| `render.yaml` | запуск на Render |
| `.env` | ключи — **только локально, никуда не выкладывать** |

История чатов хранится в браузере каждого пользователя — сервер её не сохраняет,
и люди не видят чужие чаты.
